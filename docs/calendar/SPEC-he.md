# יומן + קביעת פגישות עצמית ללקוחות — אפיון קצר (2026-11-16)

בקשת בעל העסק: "יומן שמסתנכרן עם היומן שלך, קופצות ממנו התראות עם האנימציה, ואפשר לשלוח ללקוחות גישה ליומן — בלי שיראו מי קבע ומה, רק אילו שעות פנויות — והם קובעים לבד, כותבים את תוכן הפגישה, ומקבלים הזמנה באימייל."

שרת: `feat/calendar-booking` (מיגרציה 0106). אפליקציה: `feat/calendar-booking`.

## החלטות (ברירות מחדל — אפשר לשנות)

| נושא | החלטה |

| מה עולה לשרת | **רק שעות התחלה וסיום** של אירועים "תפוסים" (לא "פנוי", לא מבוטל) מהיומנים שבעל העסק בחר, ל־60 יום קדימה. בלי כותרת, משתתפים, מיקום או שם יומן. |

| דף ציבורי | `/book/<קישור לא ניחוש>`. מציג שם/לוגו העסק ו**רק** שעות פנויות. בעל העסק יכול ליצור קישור חדש (הישן מת) או לכבות. |
| מניעת כפל | נעילה לכל עסק בתוך הטרנזקציה + אילוץ exclusion במסד (gist) כגיבוי. |

| ניווט | כפתור "יומן" בפעולות המהירות של **ניהול** + נתיב `/calendar` להתראות. סרגל הניווט התחתון לא שונה. |

## מסכים

- **יומן**: תצוגת יום/שבוע, ניווט בין ימים, כרטיס פגישה (שעה, שם, תוכן, חיוג/וואטסאפ/אימייל, ביטול), שורות "תפוס ביומן שלך", שורת סטטוס סנכרון, כרטיס "חיבור היומן של האייפון", כפתור "שתף קישור לקביעת פגישה" (וואטסאפ / שיתוף / העתקה).
- **הגדרות יומן**: הפעלה, הקישור + קישור חדש, שעות פעילות לכל יום, שם הפגישה, אורך, הפסקה, התראה מראש, כמה זמן קדימה, התראות, יומני האייפון לקריאה ולכתיבה, ניתוק.
- **דף ציבורי (שרת)**: רשימת שעות פנויות 7 ימים בעמוד → טופס (שם, טלפון, אימייל, על מה הפגישה) → אישור + "הוספה ליומן" + "ביטול או שינוי מועד". בלי JavaScript.

## אבטחה ופרטיות

- הדף הציבורי מחזיר רק זמני התחלה/סיום פנויים (בדיקה אוטומטית שאין שם/הערות/אימייל/טלפון).
- הגבלת קצב: 60 צפיות לדקה ל־IP, 10 קביעות/ביטולים לשעה ל־IP ולקישור; שדה מלכודת לבוטים; עד 3 פגישות עתידיות ללקוח, עד 30 קביעות לשעה לעסק.
- הסלאג והטוקן לא נרשמים בלוג (רק תבנית הנתיב). אין נתוני לקוח ביומן הביקורת.
- כל קריאה ציבורית עוברת דרך פונקציית SECURITY DEFINER שמחזירה רק את היקף העסק; משם הכול תחת RLS.
