# App Store screenshots

הסקריפט `../capture-preview-screenshots.sh` מריץ Preview על סימולטור iOS עם backend מדומה ושומר PNG אמיתיים מתוך ה־UI. אלה צילומי עזר בלבד; יש להשוות ל־Release הסופי ולאמת שלא השתנו המסכים לפני שימוש בחנות.

שמרו כאן צילומי מסך מקוריים של build מועמד, לפי גדלי המכשיר והשפות הזמינים ב־App Store Connect. לפני העלאה:

- לצלם רק עם נתוני דמה.
- לוודא זכויות/הסכמה עבור תמונות פרופיל או תמונות פנים שמופיעות במסכים. חלק מהתמונות מגיעות מנכסי עיצוב לדוגמה; עד לאימות זכויות, אין להשתמש בצילומים כמדיה שיווקית סופית.
- לבדוק שכל טקסט עברי קריא, אין overflow או מסכי שגיאה, ואין פרטי משתמש/לקוח אמיתיים.
- לכסות את הבית, ניהול, יצירת מסמך, לקוחות, הוצאות ודוחות.
- לא להוסיף מסגרות מכשיר או פרטי ממשק שיווקיים לצילום שנועד להיות צילום מסך רגיל של האפליקציה.
